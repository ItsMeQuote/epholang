
# Epholang Roadmap

[ [**English**](ROADMAP.md) | [Russian](ROADMAP.ru.md ]

This document describes the planned development of Epholang.

The roadmap is subject to change. Features and priorities may be
updated, postponed or removed as development progresses.

## Version 0.1.0 — Released

The first public release of Epholang.

## Version 0.2.0 — Planned

### Language changes
- [ ] Remove default parameter values.
- [ ] Introduce the new function declaration syntax.

### Standard library
- [ ] Introduce the `strings` module.
- [ ] Add the `input()` function.

### Improvements
- [ ] Fix known parser and interpreter issues.
- [ ] Improve error messages.

## Future development

### Type system
- [ ] Union types.
- [ ] Nested lists.

### Language features
- [ ] Error handling as values.
- [ ] `datatable`.

### Compiler
- [ ] Develop a native compiler.

## Notes

- No release dates are guaranteed.
- The roadmap does not represent a commitment to implement every listed feature.
- Breaking changes may occur between versions.
