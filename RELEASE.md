# Epholang 0.3.0 "Beta" (β)

November 24, 2026. This release introduces indentation-based blocks, union types, explicit function results and discards, and the EphoFMT formatter. See the changelog and 0.2 migration guide in the source archive.

| System | Filename target |
| --- | --- |
| Windows Intel/AMD or ARM | x86_64-pc-windows-msvc or aarch64-pc-windows-msvc (.zip) |
| macOS Intel or Apple Silicon | x86_64-apple-darwin or aarch64-apple-darwin (.tar.gz) |
| Debian 12, Ubuntu 22.04 and Fedora | x86_64-unknown-linux-gnu or aarch64-unknown-linux-gnu (.tar.gz, Ubuntu 22.04 glibc baseline) |
| Alpine or standalone Linux executable | x86_64-unknown-linux-musl or aarch64-unknown-linux-musl (.tar.gz) |
| VS Code | epholang-language-0.3.0.vsix |

Extract the archive for your system. Run `epholang check program.epho` to verify a program. Install the editor package with `code --install-extension epholang-language-0.3.0.vsix`. SHA256SUMS lists the archive and extension digests.
