# Переход с Epholang 0.2 на 0.3 (β)

В объявлениях тип ставится перед именем. Например, `value int := 7` становится `int value := 7`. Заголовок `function Square(x int) int {` заменяется на `function Square(int x) -> int:`. Уберите закрывающие фигурные скобки блоков, используйте один таб на уровень и замените `otherwise if` и `otherwise` на `else if` и `else`.

```epholang
function Square(int x) -> int:
	return int x * x

function Display(int result) -|:
	Output(result)

Display(Square(7))
```

Сохраняйте `-> none` и `return none null`, когда вызывающему коду нужно значение null. Для процедуры укажите `-|` и уберите return. У Output больше нет результата. Для намеренного отбрасывания значения пишите `_ = Square(7)`. Одиночный знак подчёркивания допустим только слева в этой инструкции. Вместо TypeOf импортируйте модуль types и используйте types:CurrentTypeOf.

Установите CLI и расширение одной версии. После исправления синтаксиса выполните `epholang check program.epho`, `epholang format --check program.epho` и `epholang run program.epho`.

## Разберите места вызовов

Если результат нужен, сохраните его в переменной или передайте как аргумент. Если важны только побочные эффекты вызова с результатом, используйте явное отбрасывание. Для функции, которая только печатает, укажите -| и вызывайте её отдельной инструкцией. Если код полагался на настоящее значение null, сохраните тип none и отдельный return.

Если прежний код возвращал результат Output, перенесите вызов Output на собственную строку. Для функции с результатом добавьте отдельный типизированный возврат. Переменную с именем из одного подчёркивания переименуйте. У имён вроде _count по-прежнему должен быть хотя бы один пользователь.

## Проверьте перенос

Сначала устраните синтаксические ошибки. Затем запустите статическую проверку и проверьте все места, где результат вызова раньше игнорировался. Отформатируйте файл командой format и запустите его с обычными и граничными входными данными. В CI используйте format --check.
