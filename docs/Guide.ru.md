# Руководство по Epholang 0.3 Beta (β)

## Установка и первый запуск

Загрузите архив для своей ОС и архитектуры со [страницы выпуска](https://github.com/ItsMeQuote/epholang/releases/tag/0.3.0). Для Windows и macOS доступны сборки x86-64 и ARM64. Для Debian, Ubuntu и Fedora используйте вариант Linux с glibc, для Alpine — с musl. Сравните SHA-256 скачанного файла с записью в `SHA256SUMS`. Распакуйте архив, откройте терминал в каталоге программы или добавьте этот каталог в PATH.

Создайте файл `hello.epho` в UTF-8.

```epholang
Output("Hello, Epholang!\n")
```

Команда `epholang check hello.epho` проверит программу. Команда `epholang run hello.epho` проверит её и выведет приветствие. В Windows из каталога с распакованным файлом можно выполнить `.\epholang.exe run hello.epho`.

## Типы, блоки и возвращаемые значения

В объявлении сначала укажите тип, например `int count := 1`. Значение меняется через `count = 2`. Тип `int | str` допускает целое число или строку. Списки задаются через `list<int>{1, 2}`. Первый индекс списка или строки — 1. При чтении строки по индексу возвращается один скаляр Unicode.

Заголовок блока заканчивается двоеточием. Отступ на каждом уровне — один таб. Условие `if` или `loop` должно иметь тип `bool`. В цикле по списку используйте `loop item in items:`. `skip` переходит к следующей итерации, а `break` завершает ближайший цикл.

Функция `-> T` возвращает значение на каждом пути выполнения. Например, `-> none` возвращает значение `null` через `return none null`. Функция `-|` заканчивается после последней инструкции, как встроенная `Output`. Значение самостоятельного выражения следует использовать или явно отбросить через `_ = expression`.

```epholang
function Double(int value) -> int:
	return int value * 2

function PrintValue(int value) -|:
	Output("#{Double(value)}\n")

PrintValue(21)
```

## Инструменты

- `check` проверяет типы, объявления и правила использования значений.
- `run` выполняет программу после проверки.
- `tokens` и `parse` показывают токены и дерево разбора.
- `format` форматирует синтаксически корректный файл. `format --check` проверяет формат и сохраняет файл в исходном виде.

Установите `epholang-language-0.3.0.vsix` через **Extensions → Install from VSIX**. Если интерпретатор отсутствует в PATH, укажите полный путь к нему в `epholang.executablePath`.
