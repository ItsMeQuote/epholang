\[ [English](README.md) | [**Русский**](README.ru.md) \]

Epholang — язык программирования, построенный вокруг нескольких простых идей:

- **Минимум способов на одну задачу.** Меньше пересекающихся возможностей — меньше несущественных вариантов выбора.
- **Явность важнее краткости**. Код не обязан быть коротким. Он должен быть понятным и легко читаемым.
- **Строгость вместо снисходительности.** Неиспользуемые переменные, отсутствие `return` и несоответствие типов — это всё ошибки, а не предупреждения.
- **Изменения видны в коде.** Если данные меняются, это можно увидеть в коде.
- **Традиция — не аргумент.** Индексы списков начинаются с 1. Отрицательные числа записываются как `(-1)`.
- **Никакого классического ООП.** Нет классов, наследования и методов.

> **Статус:** ранний и экспериментальный (`0.1.0`).
>
> Текущая реализация — интерпретатор с обходом синтаксического дерева (tree-walking interpreter), включающий полноценный этап статической проверки.
>
> Синтаксис и поведение могут измениться несовместимым образом. Планируется создание нативного компилятора.

## Знакомство с Epholang

```epholang
greet func := function(name str = "") str {
    if name == "" {
        return str "Привет!"
    } otherwise {
        return str "Привет, #{name}!"
    }
}

output("#{greet()}\n")
output("#{greet(\"Мир\")}\n")
```

```text
Привет!
Привет, Мир!
```

---

```epholang
nums ls<num> := list<num>{10, 20, 30}
nums = insert(nums, 1, 5)
nums = remove(nums, 2)

total num := 0
cycle n in nums {
    total = total + n
}

output("#{nums}: количество элементов — #{length(nums)}, сумма = #{total}\n")
```

```text
list{5, 20, 30}: количество элементов — 3, сумма — 55
```

## Ошибки, указывающие на проблему

Все статические ошибки сообщаются одновременно, **до того**, как программа начнётся:

```epholang
name str := "Epholang"
name = 2026
output(name)
```

```text
Static error: Cannot assign num to 'name' of type str
 --> example.epho:2:8
  |
2 | name = 2026
  |        ^^^^
```

Существует три типа ошибок:

|      Тип        |         Когда         |    Сколько    |
| :-------------: | :-------------------: | :-----------: |
| `Syntax error`  |  во время чтения кода | только первая |
| `Static error`  |   перед выполнением   |      все      |
| `Runtime error` |  во время выполнения  | только первая |

## Начало работы

### Установка

Предварительно собранные исполняемые файлы для Windows доступны на странице [Releases](../../releases).

### Самостоятельная сборка из исходного кода

Вам понадобится стабильный набор инструментов [Rust](https://www.rust-lang.org/tools/install).

```sh
git clone https://github.com/ItsMeQuote/epholang.git
cd epholang
cargo build --release
```

### Поддержка редакторов кода

Расширение для VS Code с подсветкой синтаксиса доступно на странице [Releases](../../releases).

Установите его с помощью команды:

```sh
code --install-extension epholang-language-0.1.0.vsix
```

### Запуск

```sh
epholang run program.epho      # проверить и запустить
epholang check program.epho    # только статическая проверка
epholang tokens program.epho   # показать вывод лексера
epholang parse program.epho    # показать синтаксическое дерево
```

Протестировано в Windows. На других платформах тоже должно работать, но это пока не проверялось.

## Обзор языка

### Типы

`num`, `str`, `bool`, `none`, `type` и списки `ls<T>`, где `T` — один из `num`, `str`, `bool` или `none`.

### Переменные

```epholang
age num := 17
age = 18      /* тип не может измениться */
```

Переменные существуют в том блоке, в котором они объявлены. Перекрытие имени из внешней области видимости — ошибка.

### Функции

```epholang
square func := function(x num) num {
    return num x * x
}

log func := function(message str) none {
    output("[log] #{message}\n")
    return none null
}
```

- В каждом `return` указан свой тип.
- Функция должна возвращать значение при любом варианте выполнения.
- У параметров могут быть значения по умолчанию.
- Функции объявляются на верхнем уровне, до того как они будут использованы.
- Функция не может присваивать значения глобальным переменным.

### Условия и циклы

```epholang
if x > 10 {
    output("больше\n")
} otherwise if x > 5 {
    output("среднее\n")
} otherwise {
    output("маленькое\n")
}

i num := 1
cycle i < 4 {
    output("#{i}\n")
    i = i + 1
}

cycle item in items {
    output("#{item}\n")
}
```

Условия должны иметь тип `bool`. Операторов `<=` и `>=` нет: используйте `i < 4` или `!(a > b)`.

### Списки

```epholang
xs ls<str> := list<str>{"a", "b"}
output(xs[1])                     /* первый элемент */
output(xs[length(xs)])            /* последний элемент */
xs[1] = "z"
xs = insert(xs, 2, "c")           /* возвращает новый список */
xs = remove(xs, 1)                /* возвращает новый список */
```

- Индексы начинаются с 1. `0`, отрицательные и дробные числа в качестве индекса — ошибки.
- Присваивание списка создаёт его независимую копию.
- `==` сравнивает типы списков, их длину и значения элементов с учётом порядка.

### Строки

```epholang
output("Привет, #{name}!\n")     /* интерполяция: любое выражение */
output("Буквально: \#{name}\n")  /* экранирование */
output(length("Привет!"))        /* 7, считает символы */
```

`output` никогда не добавляет символ новой строки автоматически. Используйте `\n`. Строки не объединяются с помощью `+`; вместо этого используйте интерполяцию или `output` без переноса строки.

### Числа

```epholang
x num := (-1)      /* унарный минус — только внутри скобок */
output(2 ^ 3 ^ 2)  /* возведение в степень, правоассоциативный оператор: 512 */
output(7 % 3)
```

### Комментарии

Поддерживаются только многострочные комментарии, которые могут быть вложенными:

```epholang
/* внешний
	/* внутренний */
	всё ещё комментарий
*/
```

### Встроенные функции

|           Функция            |                      Описание                       |
| :--------------------------: | :-------------------------------------------------: |
|       `output(value)`        |                  выводит значение                   |
|         `length(x)`          | количество символов в строке или элементов в списке |
| `insert(list, index, value)` |        новый список со вставленным значением        |
|    `remove(list, index)`     |              новый список без элемента              |
|       `typeOf(value)`        |          тип значения, например `ls<num>`           |

## Пока не реализовано

- ввод от пользователя
- union-типы и вложенные списки
- обработка ошибок как значения
- `datatable`
- нативный компилятор
