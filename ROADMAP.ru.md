
# Планы развития Epholang

[ [**English**](ROADMAP.md) | [Russian](ROADMAP.ru.md) ]

В этом документе описывается планируемое развитие Epholang.

Планы могут изменяться: возможности и приоритеты могут
пересматриваться, переноситься или исключаться.

## Версия 0.1.0 — Выпущена

Первый публичный выпуск Epholang.

## Версия 0.2.0 — Запланирована

### Изменения языка
- [ ] Удаление значений параметров функций по умолчанию.
- [ ] Новый синтаксис объявления функций.

### Стандартная библиотека
- [ ] Добавление модуля `strings`.
- [ ] Добавление функции `input()`.

### Улучшения
- [ ] Исправление известных ошибок парсера и интерпретатора.
- [ ] Улучшение сообщений об ошибках.

## Будущее развитие

### Система типов
- [ ] Объединённые типы (Union types).
- [ ] Вложенные списки.

### Возможности языка
- [ ] Обработка ошибок в виде значений.
- [ ] `datatable`.

### Компилятор
- [ ] Разработка нативного компилятора.

## Примечания

- Даты будущих релизов не гарантируются.
- Наличие возможности в Roadmap не означает обязательство её реализовать.
- Между версиями могут появляться несовместимые изменения.
