
# План развития Epholang

[English](ROADMAP.md) &bull; [**Русский**](ROADMAP.ru.md)

Этот документ описывает развитие Epholang, включая завершённые этапы и возможные будущие улучшения.

Epholang — экспериментальный язык программирования. Возможности, приоритеты и планы выпуска могут меняться по мере развития языка.

## Версия 0.1.0 — Выпущена

Первый публичный выпуск Epholang.

### Основные возможности языка

- [x] Добавлены переменные со статической типизацией.
- [x] Реализованы функции с явными типами параметров и возвращаемых значений.
- [x] Добавлены условные конструкции и циклы.
- [x] Реализованы списки с индексацией с 1.
- [x] Добавлена интерполяция строк.
- [x] Реализованы вложенные блочные комментарии.

### Инструменты

- [x] Реализован интерпретатор с обходом синтаксического дерева.
- [x] Добавлена статическая проверка перед выполнением программы.
- [x] Реализован интерфейс командной строки (CLI).
- [x] Добавлена базовая подсветка синтаксиса для VS Code.

## Версия 0.2.0 — Выпущена (Alpha)

Крупное обновление синтаксиса Epholang, системы типов, стандартной библиотеки и инструментов разработки.

### Изменения языка

- [x] Тип `num` заменён на `int` (`i64`) и `flt` (`f64`).
- [x] Введены явные преобразования между числовыми типами.
- [x] Добавлен новый синтаксис объявления функций `function Name(...) type { ... }`.
- [x] Удалены значения параметров функций по умолчанию.
- [x] Ключевое слово `cycle` заменено на `loop`.
- [x] Принято соглашение PascalCase для именования функций.

### Стандартная библиотека

- [x] Добавлен модуль `strings`.
- [x] Добавлен модуль `math`.
- [x] Добавлен модуль `types`.
- [x] Добавлена функция `Input()` для консольного ввода.
- [x] Добавлена функция `Includes()` для поиска подстрок и элементов списков.
- [x] Реализована `math:RandomInterval()` с обеими включёнными границами.
- [x] Реализованы явные преобразования типов.

### Улучшения

- [x] Исправлены известные проблемы парсера и интерпретатора.
- [x] Улучшены сообщения об ошибках и проверки во время выполнения.
- [x] Добавлены проверки переполнения целых чисел и точности числовых операций.
- [x] Расширен набор модульных и интеграционных тестов.
- [x] Обновлены подсветка синтаксиса и сниппеты VS Code.
- [x] Добавлены автоматические проверки через GitHub Actions.
