
# План развития Epholang

[English](ROADMAP.md) &bull; [**Русский**](ROADMAP.ru.md)

Этот документ описывает развитие Epholang, включая завершённые этапы и возможные будущие улучшения.

Epholang — экспериментальный язык программирования. Возможности, приоритеты и планы выпуска могут меняться по мере развития языка.

Текущий выпуск — 0.3.0 Beta. Открытые вопросы собраны в разделе [«После Beta»](#после-beta).

## Версия 0.1.0 — Выпущена

Первый публичный выпуск Epholang.

### Основные возможности языка

- [x] Добавлены переменные со статической типизацией.
- [x] Реализованы функции с явными типами параметров и возвращаемых значений.
- [x] Добавлены условные конструкции и циклы.
- [x] Реализованы списки с индексацией с 1.
- [x] Добавлена интерполяция строк.
- [x] Реализованы вложенные блочные комментарии.

### Инструменты

- [x] Реализован интерпретатор с обходом синтаксического дерева.
- [x] Добавлена статическая проверка перед выполнением программы.
- [x] Реализован интерфейс командной строки (CLI).
- [x] Добавлена базовая подсветка синтаксиса для VS Code.

## Версия 0.2.0 — Выпущена (Alpha)

Крупное обновление синтаксиса Epholang, системы типов, стандартной библиотеки и инструментов разработки.

### Изменения языка

- [x] Тип `num` заменён на `int` (`i64`) и `flt` (`f64`).
- [x] Введены явные преобразования между числовыми типами.
- [x] Добавлен новый синтаксис объявления функций `function Name(...) type { ... }`.
- [x] Удалены значения параметров функций по умолчанию.
- [x] Ключевое слово `cycle` заменено на `loop`.
- [x] Принято соглашение PascalCase для именования функций.

### Стандартная библиотека

- [x] Добавлен модуль `strings`.
- [x] Добавлен модуль `math`.
- [x] Добавлен модуль `types`.
- [x] Добавлена функция `Input()` для консольного ввода.
- [x] Добавлена функция `Includes()` для поиска подстрок и элементов списков.
- [x] Реализована `math:RandomInterval()` с обеими включёнными границами.
- [x] Реализованы явные преобразования типов.

### Улучшения

- [x] Исправлены известные проблемы парсера и интерпретатора.
- [x] Улучшены сообщения об ошибках и проверки во время выполнения.
- [x] Добавлены проверки переполнения целых чисел и точности числовых операций.
- [x] Расширен набор модульных и интеграционных тестов.
- [x] Обновлены подсветка синтаксиса и сниппеты VS Code.
- [x] Добавлены автоматические проверки через GitHub Actions.

## Версия 0.3.0 («Beta», β) — выпущена 24 ноября 2026 года

В Beta изменились структура блоков, правила возврата значений и способы описания переменных, которые могут хранить значения разных типов. Руководство по миграции сопоставляет синтаксис Alpha и Beta, а журнал изменений фиксирует состав выпуска. [Переход с 0.2](MIGRATION.ru.md) · [Журнал изменений](CHANGELOG.ru.md)

| Область | Что вошло в Beta | Где посмотреть |
| --- | --- | --- |
| Синтаксис | Блоки с двоеточием и табуляцией, тип перед именем, `else if` и `else`, многострочные логические выражения и вложенная интерполяция в одной строке | [Справочник языка](docs/Language-Reference.md) |
| Функции и проверки | Явный тип результата, процедуры, обязательное использование или отбрасывание значения выражения, диагностика неиспользуемых имён и рекурсии | [Функции и результаты](docs/Functions-and-Results.md) |
| Управление выполнением | `break` и `skip` внутри циклов | [Ветвления и циклы](docs/Control-Flow.md) |
| Типы и текст | Объединения типов, списки с элементами нескольких типов, индексация строк с единицы, получение объявленного и текущего типа, разбиение строки на скаляры Unicode | [Списки и текст](docs/Collections-and-Text.md) |
| Стандартная библиотека | Проверка регистра букв ASCII и диапазоны букв в обоих направлениях с включёнными границами | [Стандартная библиотека](docs/Standard-Library.md) |
| Редактор и поставка | EphoFMT для CLI и VS Code, пакет VSIX, контрольные суммы и архивы CLI для x86-64 и ARM64 под Windows, macOS и Linux (glibc и musl) | [Файлы выпуска](https://github.com/ItsMeQuote/epholang/releases/tag/0.3.0) · [Проверка релиз-кандидата](https://github.com/ItsMeQuote/epholang/actions/runs/45407953026) |

## После Beta

Эти направления уже рассматривались в проекте. Номер будущей версии и сроки для них пока не определены. В последнем столбце указаны вопросы, по которым можно оценивать дальнейшую работу.

| Область | Что доступно в 0.3 | Открытые вопросы |
| --- | --- | --- |
| Типы и статическая проверка | Объединение может описывать переменную или элемент списка. Элементы списка — скалярные значения. | Исследовать вложенные списки и пользовательские типы. До выбора синтаксиса определить правила объявления, индексации, присваивания и диагностики. |
| Обработка ошибок | Некорректное преобразование и выход за границы могут остановить выполнение. Для некоторых операций есть предварительная проверка, например `IsConvertible`. | Изучить представление ошибок как значений. Как вызывающий код распознает ошибку и как это согласуется с обязательным использованием результата? |
| Модули | Встроенные `strings`, `math` и `types` импортируются под псевдонимом. | Исследовать импорт пользовательских модулей, видимость имён, порядок загрузки и циклические зависимости. |
| Числа и библиотека | Числовые типы различаются. Потеря точности при делении целых чисел или преобразовании может вызвать ошибку. | Проверить правила точности на практических примерах. Подбирать дополнения к существующим и новым модулям под конкретные задачи и описывать граничные случаи. |
| Инструменты и документация | CLI проверяет, выполняет и форматирует программы. Расширение поддерживает подсветку, сниппеты и форматирование. Выпуск собирается для нескольких платформ. | Улучшать объяснения ошибок и полноту Wiki, исследовать помощь в редакторе и расширять проверки исполнения на разных платформах. |
| Нативный компилятор | Выпущенный интерпретатор выполняет программу обходом синтаксического дерева. | Сравнить способы компиляции и требования к среде выполнения. Для первого прототипа можно сопоставить вывод и ошибки небольшой программы с поведением интерпретатора. |

Текущее поведение описывают [руководство по Beta](docs/Guide.ru.md) и [Wiki](https://github.com/ItsMeQuote/epholang/wiki). Будущие эксперименты могут измениться или уступить место другим задачам.
