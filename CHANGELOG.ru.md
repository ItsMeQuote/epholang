# История изменений Epholang

[English](CHANGELOG.md) &bull; [**Русский**](CHANGELOG.ru.md)

Здесь перечислены значимые изменения языка.

## 0.2.0 alpha

### Изменено (несовместимо с 0.1.0)

- Тип `num` разделён на `int` (`i64`) и `flt` (`f64`); смешанная арифметика требует явных преобразований.
- Объявление `name func := function(...) type { ... }` заменено на `function Name(...) type { ... }`.
- Удалены значения параметров по умолчанию.
- Встроенные функции переименованы в PascalCase (`Output`, `Input`, `Length`, `Includes`, `Insert`, `Remove`, `TypeOf`). Для пользовательских функций PascalCase — соглашение, а не ограничение.
- Ключевое слово `cycle` заменено на **`loop`** как для циклов с условием, так и для перебора списков.
- Индексы списков и результат `Length()` имеют тип `int`.

### Добавлено

- Встроенные модули `strings`, `math`, `types` с вызовами вида `псевдоним:Функция(...)`.
- `math:RandomInterval(минимум, максимум)` с обеими включёнными целочисленными границами.
- Преобразования `types:Convert` и `types:IsConvertible`.
- Функции `Input()` и `Includes()`.
- Дополнительные CLI-тесты и обновлённая подсветка/сниппеты VS Code.

### Особенности

- Для `int / int` требуется точное представление частного в `flt`: например, `1 / 3` вызывает ошибку выполнения.
- Union-типы, вложенные списки, пользовательские модули и нативная компиляция пока недоступны.

## 0.1.0

Первый публичный выпуск Epholang.

### Добавлено

- Переменные и система статической проверки типов.
- Функции с явно указанными типами параметров и возвращаемых значений.
- Значения параметров по умолчанию.
- Условные конструкции `if` и `otherwise`.
- Циклы `cycle`.
- Списки с фиксированными типами элементов и индексацией с 1.
- Интерполяция строк.
- Вложенные блочные комментарии.
- Встроенные функции:
  - `output`
  - `length`
  - `insert`
  - `remove`
  - `typeOf`
- Интерпретатор.
- Интерфейс командной строки (CLI).
- Статическая проверка кода до запуска программы.
- Расширение VS Code с подсветкой синтаксиса.

### Поддержка платформ

- Готовый исполняемый файл для Windows.
- Возможность сборки из исходного кода с помощью Rust.
